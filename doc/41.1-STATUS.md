# Shen 42 port status

The filename is retained for existing links; this is the status of the current
Shen 42 port, not the earlier 41.1 or first ShenOSKernel-42 bring-up.

The vendored kernel is the August 2026 S42 refresh: 15 upstream KLambda files
plus retained community extensions in `klambda/`. The standard library is
vendored separately as Shen source under `lib/StLib/` and loaded at boot. The
old `compiler.kl`, `init.kl`, and `stlib.kl` are not present. See
[kernel provenance](../klambda/PROVENANCE.md) and
[standard-library provenance](../lib/StLib/PROVENANCE.md) for exact source,
file lists, and boot-order details.

The kernel initializes at load time; `boot.lua` then loads the standard
library. `P.initialise()` remains the port's public boot step, but the upstream
`shen.initialise` function described in early bring-up notes no longer exists.
The CLI and `shen.boot()` perform both steps.

The vendored kernel suite reports **134/134 passed** with `make certify` on
LuaJIT; `make test` runs the separate port-authored specs. The suite exercises
pattern matching, Prolog, parsers, and typed-mode programs. A passing suite
establishes coverage of those tests, not a proof of every program's behavior.
The default LuaJIT path uses native Prolog/typecheck accelerators with a legacy
fallback; use `SHEN_PROLOG_ENGINE=legacy make certify` to exercise the latter.

For current benchmark methodology and dated measurements, see
[BENCHMARKS.md](BENCHMARKS.md). The original 21-file bring-up and its
pre-cache timing figures were for an earlier kernel tree, not this release.
The [original bring-up report](https://github.com/pyrex41/shen-lua/blob/5b09a25/doc/41.1-STATUS.md)
remains available for its detailed compiler history.
